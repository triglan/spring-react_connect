# menu-app — 모험가의 식탁

`chap06-spring-data-jpa` 메뉴 API(localhost:8080)와 연동한 React 클라이언트. 전체 설명은 저장소 루트의 [README](../README.md)를 본다.

```bash
npm install
npm run dev      # http://localhost:5173 (서버 CORS 가 5173 만 허용)
npm run tokens   # design/montage.tokens.json → src/tokens.css
npm run lint
npm run build
```
